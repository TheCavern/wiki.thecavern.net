# Quests

Quests are different objectives you need to complete, which will reward you with money, and EXP. This is one of the best ways to make money when starting out.
The amount of active quests you can have at any given time depend on your rank.

There are a total of **16** categories, and **1289** total quests, each ranging in difficulty. Most quests have multiple tiers, with the quest requirement and reward increasing with each tier.

## Comands Overview
| Command | Description | 
| ------------- |:-------------:|
| /quests | View all available quests. |
| /quests cancel [quest name] | Cancel the specified quest. |
| /quests cancel * | Cancels **all active** quests.
| /quests started | View all active quests. |

> :::tip
> To make some easy money, attempt some of the **Impossible** quests.
:::
